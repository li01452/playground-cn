# 神经网络游乐场 · 中文入门版

不用写代码，也不必先学微积分。点一下“开始训练”，观察一个小型神经网络怎样从例子中学会区分橙色与蓝色的点。

本项目基于 [TensorFlow Playground](https://github.com/tensorflow/playground)，面向没有机器学习基础的中文读者。它保留原有交互实验，将网页界面与教学说明改为简体中文，并补充操作顺序、术语解释与对照实验。

## 从哪里开始

启动网页后：

1. 保留默认设置，点击左上角的 **▶ 开始训练**。
2. 看右侧：圆点是真实答案，背景是网络的预测。观察背景如何逐渐贴合两类点的分布。
3. 看训练损失与测试损失是否下降。测试点没有参与参数更新，可用于检查网络对未见数据的表现。
4. 暂停，每次只改一个设置，重新训练，对比结果。网页下方提供完整的入门说明。

建议使用电脑浏览器。实验区保留原版横向布局，小屏设备需要横向滚动。

## 可以学到什么

- **输入、隐藏层与输出**：点的坐标怎样经过神经元变成预测。
- **权重与偏置**：训练调整的参数是什么，连线粗细和颜色代表什么。
- **学习率与激活函数**：为什么步子大不一定更好，为什么非线性很重要。
- **训练与测试**：如何区分“做对练习题”和“学会可推广的规律”。
- **噪声、模型大小与正则化**：理解过拟合，以及限制模型复杂度的取舍。
- **分类与回归**：预测类别和预测连续数值有什么不同。

颜色深浅表示模型输出的数值，并不是经过校准的概率；损失也不是答错的百分比。这是基础神经网络演示，不是聊天大模型或 Transformer 模拟器。

## 三个动手实验

| 实验 | 怎样操作 | 观察什么 |
| --- | --- | --- |
| 为什么需要非线性 | 圆环数据，只开 X₁、X₂，对比 Tanh 与线性激活；再开启平方特征 | 边界能否围成圆，输入特征会怎样改变结果 |
| 学习率越大越好吗 | 同一数据上对比 0.003、0.03、3；每次先重置 | 学习速度与损失是否稳定 |
| 网络越大越好吗 | 增加噪声、减少训练数据，再增大神经网络 | 训练损失与测试损失是否出现差距 |

每次只改一个变量，尽量使用相同数据与训练轮数。初始化有随机性，可以重复几次验证。复制完整地址可分享实验配置，但不会保存已训练的权重。

## 本地运行

需要 Node.js 与 npm。已在 Node.js 24 下完成构建验证。

```bash
git clone https://github.com/li01452/playground-cn.git
cd playground-cn
npm ci
npm run build
npm run serve
```

打开终端显示的本地网址。开发时运行 `npm start`，修改 TypeScript、HTML 或 CSS 后自动重新编译。

单独检查类型：

```bash
npm run typecheck
```

构建产物位于 `dist/`，可以部署到任意静态网页托管服务。源码仓库本身不会自动变成可访问的网页；GitHub Pages 需单独启用，并使用构建后的 `dist/` 内容。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `index.html` | 中文界面、入门指引和教学说明 |
| `styles.css` | 实验区与中文阅读排版 |
| `src/playground.ts` | 交互、训练过程和动态文案 |
| `src/nn.ts` | 神经网络与反向传播实现 |
| `src/dataset.ts` | 示例数据生成 |
| `src/state.ts` | 参数和网址状态保存 |

网络计算使用项目自带的 TypeScript 实现，图形使用 D3.js，界面使用 Material Design Lite。它并不依赖 TensorFlow 执行计算。中文版本使用系统字体和字符图标，页面不加载原项目的 Google Analytics。
